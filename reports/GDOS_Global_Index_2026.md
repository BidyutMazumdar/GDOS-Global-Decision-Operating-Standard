# GDOS Global Index 2026

## Overview

The GDOS Global Index 2026 represents the first experimental ranking of countries based on decision intelligence using the GDOS framework.

---

## Methodology

The index is calculated using the GDOS core equation:

GDOS Score = (DI × CA × RP × EW) / N

Where:

- DI = Data Integrity  
- CA = Context Awareness  
- RP = Risk Projection  
- EW = Ethical Weight  
- N = Noise

## Key Insights

- Higher data integrity and risk projection significantly improve decision scores  
- Lower noise leads to exponential improvement in outcomes  
- Ethical weighting plays a stabilizing role
